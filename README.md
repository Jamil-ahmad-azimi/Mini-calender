# 📅 Modern Calendar Card App

A beautifully styled calendar card built with **HTML**, **CSS**, and **JavaScript**. It dynamically displays the current date, including the day of the month, weekday, month, and year — all in a clean, responsive design inspired by modern UI trends.

## ✨ Features

- 📆 Automatically shows today's date
- 💡 Modern split-layout design
- 🌐 Fully responsive and lightweight
- 🧠 Great for beginners learning date manipulation and styling

## 🔧 Technologies Used

- HTML5
- CSS3 (Flexbox)
- Vanilla JavaScript (Date object)

## 🚀 Getting Started

1. Clone the repository or download the source files.
2. Open `index.html` in your browser.
3. That’s it — enjoy your modern calendar UI!
